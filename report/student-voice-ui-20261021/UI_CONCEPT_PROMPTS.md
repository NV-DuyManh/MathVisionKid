## Prompt chung

Use case: ui-mockup. Create ONE polished large landscape 16:9 high resolution design presentation board for MathVisionKid, a Vietnamese primary school math learning app. Input image 1 is the mascot identity reference: preserve the cute yellow star, blue graduation cap, purple book, soft glossy 3D styling. Input image 2 is current real-app layout reference only, redesign the composition deliberately. The board must be a coherent complete UI kit, not a marketing poster. Hero row shows phone (priority and largest readable UI), tablet and laptop with vertical desktop sidebar. Below show 8 clearly separated detailed mobile screens: Lessons, Achievements, Saved work, Confirm problem, One learning step, Audio explanation, Didn't understand choices, Highlighted student work. All mobile screens balanced vertically, calm hierarchy, one main task per screen, no piles of panels, no giant empty bottoms. Use Vietnamese text sparingly and accurately: 'MathVisionKid', 'Chào em!', 'Chụp bài toán', 'Bài học', 'Thành tích', 'Của em', 'Nghe giảng', 'Em đã hiểu', 'Em chưa hiểu', 'Chọn chỗ em còn vướng'. Audio screen has two clear buttons after audio and followup choices, not long lists of voices. Keep realistic implementation, high contrast text, large child-friendly tap areas. Beautiful consistent approved 3D wallet/book/progress/calculator icons. No developer UI, no watermarks.
