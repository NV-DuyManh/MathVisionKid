# PHASE 2.1 — RESEARCH REPRODUCIBILITY & METRIC PROVENANCE REPORT

## Executive Summary

Phase 2.1 of the Analytics Metric Integrity Audit & Fix has been successfully completed. 
The core objective was to add a **Research Reproducibility Layer** to the HandAI Analytics system without altering the core CRNN inference, OCR pipeline, or AI correction logic. This ensures that all exported metrics and trial evaluations are strictly research-grade, properly sourced, and reproducible for academic defense.

## Key Enhancements

### 1. `groundTruthStatus` Injection
The `TrialAnalytics` model now natively calculates and tracks the explicit status of the ground truth used for evaluation:
- `EXPLICIT`: An authoritative ground truth text was provided.
- `USER_CONFIRMED`: A human user validated the prediction via a UI verdict (e.g., `CONFIRMED`, `AI_CORRECTED`, `WRONG`, `MANUAL_EDIT`).
- `MISSING` / `FALLBACK`: The prediction was not validated and is merely a fallback string.

> [!IMPORTANT]
> **Research Integrity Enforcement**: Any evaluation where the `groundTruthStatus` is `FALLBACK` or `MISSING` is now strictly excluded from the calculation of research metrics (CER, WER, Character Accuracy).

### 2. Metric Provenance Integration
All data exports generated by the analytics engine now guarantee metric traceability by embedding a `metricProvenance` layer:
```json
"metricProvenance": {
  "metricVersion": "v2.1",
  "method": "GroundTruthBasedEvaluation",
  "calculationTimestamp": "2026-09-23T...",
  "evaluationScope": "TRIAL_SCOPED"
}
```

### 3. Edge-Case Refinements
- **Empty OCR Detection**: When the model returns empty results for both OCR and final text (e.g. segmentation or detection failure), the prediction is properly marked as `Detection Failed`, flagged as a `SEGMENTATION_ERROR`, and given a `MISSING` ground truth status (unless an explicit reference is provided).
- **Expanded Verdict Taxonomy**: Verdicts such as `WRONG`, `FAILED`, and `INCORRECT` are now mapped as `USER_CONFIRMED` because an explicit user invalidation represents valid ground truth for calculating accuracy drops.
