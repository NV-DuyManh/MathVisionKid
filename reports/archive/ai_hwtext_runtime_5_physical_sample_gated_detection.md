## 2. Technical Implementation

### A. Adaptive Chromatic-Ink Extraction
1. **Hue Histogram**: The image is converted to HSV. Candidate colored ink pixels are isolated using high saturation (`> 30`) and dark value (`< 230`).
2. **Dominant Peak**: A 180-bin histogram dynamically finds the dominant hue peak (e.g. `118` for the physical sample).
3. **Circular Masking**: An ink mask is generated by allowing a `±15` circular hue variance around the dominant peak. This securely isolates the blue/purple pen while natively ignoring the desaturated gray grid lines.
4. **Conditional Morphology**: If a chromatic cluster is found, the aggressive vertical/horizontal morphological grid subtraction is bypassed entirely. This prevents destructive splitting of t-crossbars or cursive connections.

### B. Image-Relative Projection Segmentation
- The 1D row projection now operates on a **vertically closed mask** (`height * 0.05`). This naturally bridges large intra-line vertical gaps (e.g., between Vietnamese diacritics and base characters) that were otherwise splitting the line horizontally.
- An **image-relative** projection threshold (`width * 0.005`) replaces the former synthetic fixed threshold, preventing short but solid lines from being ignored.
- Over-merged lines (due to vertical closing bridging small inter-line gaps) are gracefully recovered using the existing **Recursive Giant-Box Split** logic, which accurately splits at local valleys in the smoothed 1D projection.
