# Experiment Workspace

This directory tracks ML experiments, metrics, and reports.

The Proposal v3.1 specifies the use of **MLflow** for tracking:
- Parameters
- Metrics
- Artifacts
- Experiment comparisons

The AI/ML teammate will later store evaluation outputs here. Relevant metrics may include critical-token accuracy, recognition accuracy, layout accuracy, first-error precision/recall, coverage, over-correction rate, and latency.
