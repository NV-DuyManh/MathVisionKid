## Triển khai và rollback

Đích: ứng dụng MathVisionKid hiện có tại `edu.mathvision.online`, `api.mathvision.online` và các workspace web liên quan có source thay đổi. Chỉ cập nhật container ứng dụng thuộc Compose project `mathvisionkid` trong `/home/dtu/mathvisionkid`; dựng revision phát hành trong thư mục mới và giữ image trước đó. Inventory ID/image/mount container và hash cấu hình bảo vệ trước khi ghi; sao lưu PostgreSQL, catalog và cấu hình vào thư mục backup mới, xác minh đọc được. Migration V35 thêm lựa chọn hiện tên; kiểm tra migration đã có trước khi chạy, giữ nguyên dữ liệu và cấu hình hiện hữu.

Không recreate DB/Redis/MinIO/gateway hay dịch vụ khác, không prune/reboot hoặc đổi SSH/firewall. Sau rollout đối chiếu container ngoài phạm vi và hash cấu hình, kiểm tra API xác thực, gợi ý, lưu lựa chọn hiện tên và các route web thực tế. Ghi image/deployment IDs và kết quả live trong receipt riêng.

Nếu smoke lỗi, rollback đúng image ứng dụng hoặc deployment web trước đó; giữ schema cộng thêm và dữ liệu đang nhận ghi, không restore đè DB. Source release/tag không đồng nghĩa đã triển khai hoặc phát hành store. Không tuyên bố kiểm thử điện thoại vật lý hay nghe âm thanh khi chỉ kiểm tra browser/HTTP.
