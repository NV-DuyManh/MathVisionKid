# 1.7.4 — Cập nhật dependency web và quy tắc PR

- Cập nhật Vite, Playwright và các dependency web đã kiểm tra trên Node 22.19.0. Cập nhật Student lên Expo 58.0.26 theo bảng tương thích của SDK.
- Bắt buộc nhãn loại, phạm vi và rủi ro khi merge PR. Bài kiểm thử Race trong Student CI dùng đường chạy ngắn hơn và vẫn kiểm tra các bước chính.
- Cập nhật Gradle wrapper và các pin Python trong mã nguồn. Đợt triển khai này áp dụng cho Portal/Student Web và Admin Web. Không có migration cơ sở dữ liệu.

## Kiểm thử và triển khai

- Quality gate trên develop, PR phát hành và main phải đạt. Kiểm tra Portal, Student và Admin trên desktop/mobile, gồm đăng nhập, chuyển vai trò, route bảo vệ và hiển thị sao đã ghi nhận.
- Giữ ID các deployment hiện hành để quay lại theo từng dự án nếu smoke thất bại. Đối chiếu lịch sử sao trước/sau bằng truy vấn chỉ đọc. Đợt này không triển khai Teacher hay thay runtime trên VPS.
