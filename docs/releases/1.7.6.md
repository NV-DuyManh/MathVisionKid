# 1.7.6 — Hồ sơ và lịch sử sao trên Student Web

- Khôi phục giao diện Hồ sơ và Thành tích trên desktop. Lịch sử sao có phân trang và tổng sao tiếp tục lấy từ hồ sơ học sinh.
- Phân biệt các chặng học tập bằng màu sắc, giữ bố cục thao tác theo kích thước màn hình và cập nhật giao diện trò chơi. Đăng nhập Google có thể thử lại sau khi đóng cửa sổ.
- Phát hành Portal/Student Web cùng Business API cho [PR #194](https://github.com/NV-DuyManh/MathVisionKid/pull/194). API bổ sung đọc lịch sử sao. Bản phát hành không có migration.

## Kiểm thử và triển khai

- Kiểm tra Quality gate trên develop, PR phát hành và main. Kiểm thử lịch sử sao có phân trang, trạng thái hồ sơ desktop và mobile, và hủy rồi thử lại đăng nhập Google.
- Chuẩn bị snapshot Business API và giữ deployment Portal trước khi chuyển phiên bản. Xác minh Business API trước khi chuyển tên miền Portal production.
