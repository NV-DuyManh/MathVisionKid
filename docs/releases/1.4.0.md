# 1.4.0 — Giao diện Student Web mới

Phát hành giao diện Student Web từ PR #101. Giao diện mới bao gồm trang chủ, điều hướng, đăng nhập, thư viện, màn học, camera, Quiz, trò chơi, máy tính, bài đã lưu, tiến bộ và hồ sơ. Bố cục thay đổi theo chiều rộng màn hình, với menu và tìm bài học trên desktop.

Nguồn phát hành là nhánh phát triển đã tích hợp. Quyền truy cập, API và dữ liệu vẫn do backend kiểm soát. Không có migration.

## Kiểm thử

- Kiểm tra TypeScript và hồi quy Student, gồm đăng nhập, phục hồi phiên, điều hướng bàn phím, ảnh riêng tư và dữ liệu đã lưu theo tài khoản.
- Quality gate phải đạt trên PR tích hợp, PR phát hành và commit main trước khi promote.
- Kiểm tra bản xuất Student ở /study, API cùng tên miền và các đường dẫn sâu, sau đó đăng nhập bằng tài khoản test và thử trang chủ, bài học, Quiz, trò chơi và sổ học tập trên web.

## Triển khai và rollback

Promote bản Student Web đã kiểm chứng vào Portal trên edu.mathvision.online. Ghi SHA nguồn, deployment trước và sau, và kết quả kiểm thử. Khôi phục deployment Portal trước nếu smoke production thất bại. Không cần thao tác VPS.
