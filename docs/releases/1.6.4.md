# 1.6.4 — Khôi phục ảnh Google trên Student Web

- Khi thông tin đăng nhập thiếu ảnh, Business API lấy ảnh từ hồ sơ Google đã xác thực. Tài khoản học sinh đã liên kết nhận ảnh khi đăng nhập Google lại. Ảnh tự tải lên và lựa chọn ẩn ảnh Google vẫn được ưu tiên.

## Kiểm thử và triển khai

- PR #159 đạt Quality gate, gồm kiểm tra backend, web và quy trình. Đã kiểm tra luồng Portal trên Chromium với dữ liệu giả lập cho học sinh cũ, học sinh mới, giáo viên và đăng nhập bị từ chối.
- Bản này không đổi schema hoặc cấu hình môi trường. Cập nhật Business API rồi Portal. Giữ bản Student Web đang phục vụ.
- Khi cần quay lui, dùng image Business API và deployment Portal trước đó. Không khôi phục đè cơ sở dữ liệu đang phục vụ.
