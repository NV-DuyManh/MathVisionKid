# 1.6.0 — Lộ trình xếp hạng học sinh

Học sinh có thể xem các bậc từ Sắt đến Huyền Thoại, số sao cần cho mỗi bậc và hạng cao nhất từng đạt. Bảng xếp hạng web tiếp tục bao gồm mọi khối và áp dụng cài đặt quyền riêng tư hiện có. Phần hồ sơ chỉ hiển thị số sao đã nhận một lần.

## Dữ liệu và triển khai

- V41 chỉ bổ sung cột nullable. Giữ nguyên lịch sử sao, lựa chọn danh hiệu đã lưu và cài đặt quyền riêng tư. Client cũ tiếp tục nhận các mốc xếp hạng của phiên bản mình hỗ trợ.
- Chạy kiểm tra chính sách, Student, Web và Backend trên PR. Trước khi triển khai, kiểm tra sao lưu phục hồi được trên database riêng rồi cập nhật Business API trước Portal và Student Web.
- Nếu cần quay lại, dùng deployment Portal và image API đã lưu. Đánh giá tương thích Flyway với V41 trước khi quay lui và giữ các dữ liệu phát sinh trên hệ thống.
