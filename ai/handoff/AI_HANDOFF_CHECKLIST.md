# AI Handoff Checklist

The AI/ML teammate should complete this checklist before integration.

- [ ] Dataset is de-identified
- [ ] Dataset version assigned
- [ ] Annotation schema version assigned
- [ ] Label map included
- [ ] Train/validation/test split frozen
- [ ] Writer leakage checked
- [ ] Double annotation statistics available
- [ ] Model training config saved
- [ ] Model version assigned
- [ ] Model artifact exported
- [ ] SHA-256 calculated
- [ ] Metrics exported
- [ ] Model card completed
- [ ] Dataset card completed
- [ ] Runtime dependencies documented
- [ ] Sample inference input/output available
- [ ] Known limitations documented
